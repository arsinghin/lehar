# Security

Lehar handles family plans and calls third-party AI models. These are the risks we design against and
how each one is addressed.

## Threat model

| Threat                                  | Mitigation                                                                                                                                                                                                                                                                                              | Where                                                                             |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **API key leakage**                     | Keys exist only as Vercel environment variables, read by server code. Nothing is prefixed `VITE_`, so Vite can never inline them into the bundle. `.env*` is git-ignored. CI runs a credential-shape scanner (Google `AIza…`, OpenRouter `sk-or-…`, private keys). `/api/health` reports booleans only. | `server/config.ts`, `.gitignore`, `scripts/check-secrets.mjs`, `server/health.ts` |
| **Surprise AI costs**                   | Use a Gemini key from an AI Studio project with no billing account. In code, only Gemini Flash, Flash-Lite and Gemma ids and OpenRouter `:free` ids are accepted; others are dropped at startup and tested.                                                                                             | `server/config.ts`, `server/server.test.ts`                                       |
| **Quota abuse / denial of wallet**      | Same-origin check (`Sec-Fetch-Site` / `Origin`), per-IP rate limits (8/min, 80/day), 8 KB body cap, response cache, request de-duplication in the browser, circuit breaker on 429/5xx, overall 50 s deadline.                                                                                           | `server/security/*`, `server/ai/chain.ts`, `src/lib/apiClient.ts`                 |
| **Prompt injection**                    | Free text is screened for injection patterns (422 before any model call). User data is sent as JSON inside `<event_data>` with `<` escaped, so it can't close the tag. The system prompt says data is never instructions. Output must match a strict JSON schema.                                       | `server/security/injection.ts`, `server/ai/prompts.ts`                            |
| **Harmful or misleading model output**  | zod `strictObject` validation on the server and again in the browser. The sanitiser strips URLs, emails, phone numbers, rupee amounts, tags, control and bidi characters. Every suggestion is labelled with its source, and AI never produces budget numbers.                                           | `server/security/sanitize.ts`, `server/ai/tasks.ts`                               |
| **XSS**                                 | React escaping only, with no `dangerouslySetInnerHTML` anywhere. Strict CSP: `default-src 'self'; script-src 'self'; style-src 'self'` (no `unsafe-inline`; the bundle has no inline scripts or styles, which CI checks). `object-src 'none'`, `base-uri 'self'`, `frame-ancestors 'none'`.             | `vercel.json`, `scripts/check-bundle-size.mjs`, e2e CSP test                      |
| **Clickjacking / cross-origin attacks** | `frame-ancestors 'none'`, `X-Frame-Options: DENY`, COOP `same-origin`, CORP `same-origin`.                                                                                                                                                                                                              | `vercel.json`                                                                     |
| **Transport**                           | HSTS (2 years, preload) and `upgrade-insecure-requests`.                                                                                                                                                                                                                                                | `vercel.json`                                                                     |
| **Malformed or tampered local data**    | localStorage and imported plan files are parsed with the same zod schemas (unknown keys rejected, ranges enforced). Imports are capped at 200 KB. Damaged data is discarded with a notice.                                                                                                              | `src/state/persistence.ts`                                                        |
| **Information disclosure**              | Error responses are generic with a request id. No stack traces and no echo of input. Logs are structured JSON with operational fields only, never user text or model output.                                                                                                                            | `server/http.ts`, `server/log.ts`                                                 |
| **Privacy**                             | Plans stay in the browser. AI requests omit titles, notes and names; idea requests see only a budget band. The UI shows exactly what is sent ("What Lehar sends to the AI").                                                                                                                            | `src/core/aiContext.ts`, `src/features/ideas/IdeasView.tsx`                       |
| **Supply chain**                        | Minimal runtime dependencies (`react`, `react-dom`, `zod`, `@google/genai`). The lockfile is committed and `npm ci` is used in CI. `npm audit --omit=dev --audit-level=high` runs in CI. There is no Dependabot, so the repository keeps a single branch.                                               | `package.json`, `.github/workflows/ci.yml`                                        |
| **External links**                      | Google Calendar and Maps links open with `rel="noopener noreferrer"`, and their URLs are built with `URLSearchParams`.                                                                                                                                                                                  | `src/core/calendar.ts`                                                            |

## Reporting

Please report vulnerabilities privately through a GitHub security advisory on
[arsinghin/lehar](https://github.com/arsinghin/lehar/security/advisories/new) rather than a public issue.
The maintainer is AR Singh ([@arsinghin](https://github.com/arsinghin)).
