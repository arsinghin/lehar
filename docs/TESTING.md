# Testing

`npm run verify` runs everything CI runs, except the browser e2e suite (`npm run test:e2e`).

| Layer                     | Tooling                                               | What it proves                                                                                                                                                                                                                                                                                                                                      |
| ------------------------- | ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Unit: core engines**    | Vitest                                                | Budget maths and warnings, timeline ordering, compression, delay ripple, trade-off levers and ranking, vendor comparison, parser phrasings (70+ cases), diff, calendar export, schemas                                                                                                                                                              |
| **Property-based**        | fast-check                                            | Budget lines always sum exactly with nothing negative · more guests never cost less · higher tiers never cost less · every task is due on or before the event and after its dependencies · every trade-off lever saves money and never touches a protected category · the change parser never throws on arbitrary text · day arithmetic round-trips |
| **Server / API**          | Vitest with injected fakes                            | Every guard (405, 403, 415, 413, 400, 429 + Retry-After, 422 injection), headers (`no-store`, `nosniff`, request id), caching, rules fallback, provider order, circuit breaker, deadline, invalid/empty/unsafe model output, cost allowlist, SDK request shape (JSON schema, LOW thinking, abort signal)                                            |
| **Compiled-server smoke** | `tsc` → Node                                          | The functions import and run as plain Node ESM, as on Vercel                                                                                                                                                                                                                                                                                        |
| **Browser client**        | Vitest                                                | Response validation, error mapping, caching and de-dupe, graceful fallbacks, rules-first parsing                                                                                                                                                                                                                                                    |
| **State**                 | Vitest                                                | Undo/redo, history cap, single accepted quote per category, delay clamping, persistence round-trip, corrupt/blocked storage, import validation                                                                                                                                                                                                      |
| **Components + flows**    | Testing Library + user-event + axe-core               | A combined change (+50 guests, −10% budget, 2 weeks earlier) end to end, the intake wizard with focus management, tabs keyboard pattern, trade-offs, what-if, assumptions, timeline, vendors, ideas (AI and offline), history, import/export, storage warnings. **axe reports 0 violations** on every screen and the dialog                         |
| **Contrast**              | Vitest reading `tokens.css`                           | WCAG AA ratios for every text/background pair in both themes                                                                                                                                                                                                                                                                                        |
| **End to end**            | Playwright (desktop + Pixel 7) + @axe-core/playwright | Combined-change journey under the **production CSP** · reload persistence · keyboard-only intake · dark theme with axe (real contrast) · works with no AI service · no horizontal scroll at 320 px on every tab                                                                                                                                     |

## Coverage gates (enforced in `vitest.config.ts`)

- `src/core/**`: ≥ 95% lines, statements and functions; ≥ 90% branches
- `server/**`: ≥ 95% lines, statements and functions; ≥ 88% branches
- Overall: ≥ 90% lines, statements and functions; ≥ 85% branches
